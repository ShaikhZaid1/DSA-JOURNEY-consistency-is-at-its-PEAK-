Move Zeroes to End (Two Pointer Approach)
Problem Statement

We need to move all the zeroes present in the array to the end while maintaining the relative order of the non-zero elements.

Approach

To do this we will follow these steps:

We will maintain two pointers:
i → Points to the position where the next non-zero element should be placed.
j → Traverses the entire array.
We will start both pointers from the beginning of the array.
If the current element is non-zero, we will swap it with the element at pointer i.
After every swap, we will move i one step forward.
By the end of the traversal, all the non-zero elements will be at the beginning of the array, and all the zeroes will automatically move to the end.
Code
#include<iostream>
using namespace std;

int main()
{
    int array[]={0,1,0,3,12};
    int n=5;

    int i=0;

    for(int j=0;j<n;j++)
    {
        if(array[j]!=0)
        {
            swap(array[i],array[j]);
            i++;
        }
    }

    for(int j=0;j<n;j++)
    {
        cout<<array[j]<<" ";
    }

    return 0;
}
Example

If we have the array

0 1 0 3 12

After moving all the zeroes to the end, the array becomes

1 3 12 0 0

This is because all the non-zero elements keep their original order while every zero is moved to the end.

Time Complexity

The time complexity of this solution is

O(n)

This means that every element of the array is visited only once.

Space Complexity

The space complexity of this solution is

O(1)

This means that no extra array is used, so the additional space required remains constant.
